# mindmap

> 在线思维导图网页应用（v1 / v2 两个版本）。

## 📌 项目概述

`mindmap` 是一个基于纯前端（HTML / CSS / JS）的**思维导图工具**，包含 `v1` 与 `v2` 两个迭代版本，无需任何依赖即可在浏览器中创建与编辑思维导图节点。

## 📁 目录结构

```
mindmap/
├─ v1/   # 第一版（index.html / script.js / style.css）
└─ v2/   # 第二版（功能迭代，index.html / script.js / style.css）
```

## 🚀 使用

用浏览器直接打开 `v1/index.html` 或 `v2/index.html` 即可使用。
